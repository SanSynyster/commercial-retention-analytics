# Corrected-V2 Results Package — Reproduction

Regenerate the aggregate report and four SVG figures from the accepted aggregate outputs:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python docs/recovery/COMMERCIAL_DS_007D_PACKAGE.py \
  --input-dir data/processed/corrected_v2_customer_analytics \
  --output-dir reports/corrected_v2
```

The script reads only these 007B/007C aggregate inputs (no customer-level table):

- `repeat_90d_by_first_observed_month.csv` — `population, first_observed_month, eligible_customer_count, mature_customer_count, repeat_numerator, denominator, conversion_fraction, mature_repeat_timing_count, median_days_to_second_purchase_among_mature_repeaters, insufficient_follow_up_count`
- `first_observed_cohort_activity.csv` — `population, cohort_month, month_index, activity_month, cohort_size, active_customers, activity_fraction, is_mature, is_cohort_entry, cell_status`
- `concentration_summary.csv` — `eligible_customer_count, top_decile_customer_count, top_decile_qualifying_gross, identified_qualifying_gross_denominator, top_decile_share, ranking_rule, monetary_measure, unattributed_positive_merchandise_excluded`
- `signed_merchandise_sensitivity_summary.csv` — `view_label, identified_customer_count, qualifying_positive_merchandise_rows, qualifying_positive_merchandise_amount, identified_return_cancellation_rows, identified_return_cancellation_signed_amount, signed_merchandise_sensitivity_amount, returns_only_customer_count, negative_net_customer_count, unattributed_return_cancellation_rows_excluded, unattributed_return_cancellation_signed_amount_excluded, manual_credits_included, manual_credits_bridge_identifiable_amount_separate`
- `segment_summary.csv` — `purchase_frequency, recency_state, customer_count, qualifying_gross_merchandise, share_of_identified_qualifying_gross`
- `segment_flag_summary.csv` — `flag, customer_count, qualifying_gross_merchandise`
- `reconciliation.json` — `all_customer_rows_have_unique_ids, customer_count, last_complete_activity_month, maximum_cohort_month_index, occasion_count, occasion_reference_validated_by_production_api, pooled_repeat_rate_published, qualifying_gross_merchandise, qualifying_line_count, recency_reference_date, recency_reference_date_is_partial, recency_reference_timestamp, repeat_rows_are_stratified_only`
- `value_segments_reconciliation.json` — `customer_count, customer_level_outputs_local_only, identified_returns_cancellations_signed, manual_credits_identifiable_separate, qualifying_gross_merchandise, qualifying_occasion_count, signed_bridge_validated_against_frozen_reference, unattributed_positive_merchandise_excluded, unattributed_returns_cancellations_excluded`

It writes `corrected_v2_scientific_results.md` and the SVG files in `figures/`. Inputs must be generated by the accepted local 007B and 007C paths and remain under the ignored `data/processed/` directory.

## Known limitations

The source ends partway through 2011-12-09. Only complete calendar activity months through November 2011 are plotted. First-observed month is not verified acquisition. Signed merchandise sensitivity does not link returns to original purchase invoices and excludes unattributed rows and manual credits. Segment labels and the inclusive 0–30-day flag are descriptive conventions, not validated prediction or targeting rules. This package does not recompute analytics.
